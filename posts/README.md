# Publishing a blog article

1. Add the article as an HTML file in this folder. The existing `future-of-data-analytics.html` is a reference.
2. Add its title, date, description, image and link as a new `archive-item` in `../blog.html`, above older articles.
3. Update the featured article in the `#blog` section of `../index.html` if you want the new article on the homepage.
4. Commit and push those files to the GitHub Pages publishing branch. Do not add private files or unpublished material.

Articles are added manually; this site does not automatically write or publish a daily post.
